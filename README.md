# Nova RNG

Nova RNG is a browser-based random number generator game with upgradeable mechanics, themes, and background music. Players roll to earn points, unlock upgrades, and track stats. The game includes full settings for volume control, themes, and auto-roll preferences.

---

## Features

- **Rolling System**: Standard, Auto, and Fast Auto Roll options.
- **Upgrades**: Multiple upgrade types including speed, luck, extra rolls, offline points, rebirths, and prestige multipliers.
- **Stats**: Track total rolls, points, unique items, rebirths, and prestiges.
- **Settings**:
  - Volume control (0–100) with mute toggle.
  - Theme selection (Dark, Light, Blue, Purple) that affects backgrounds, text, and elements.
  - Auto-roll and fast auto-roll start toggles (works only if upgrades are unlocked).
- **Background Music**: 21 random tracks with global mute and volume control.
- **Responsive Design**: Works on desktop and mobile devices.
- **Swipe Navigation**: Navigate between pages with horizontal swipe gestures on touch devices.
- **Popup Notifications**: Inform players of purchases, upgrades, and other actions.

---

## Installation

1. Clone or download the repository.
2. Open `index.html` in a modern browser (Chrome, Firefox, Edge, Safari).
3. Ensure `rarities.json`, `upgrades.json`, and music files (`song1.mp3` – `song21.mp3`) are in the same folder as `index.html`.
